WiFi IDS/IPS – Advanced Intrusion Detection System
 Overview

WiFi IDS/IPS is an advanced intrusion detection and prevention system designed to monitor wireless network traffic in real time and detect potential security threats using both rule-based detection and machine learning (anomaly detection).

This project simulates a SOC-style detection pipeline, combining packet analysis, alerting, and logging into a modular and scalable architecture.

🔥 Key Features
 Real-time packet sniffing using Scapy
 Detection of common attacks:
Deauthentication attacks
ARP spoofing
 Machine Learning-based anomaly detection (Isolation Forest)
 Telegram alerts for real-time notifications
 Structured JSON logging (SIEM-compatible)
 Modular and scalable architecture
 Optional dashboard for monitoring alerts
